下载项目

GitHub 仓库地址待发布

公开仓库入口将在发布后补充。当前可使用已获取的完整项目文件；不要只复制网页目录。

仓库开放后，通过 GitHub 的 Code → Download ZIP 下载并解压，或使用 Git 克隆。以下地址为占位内容，需替换后执行。

git clone <实际 GitHub 仓库地址>
cd <项目目录>

在包含 competition_app、requirements-app.txt 和 train.py 的目录打开终端。当前文件包对应“代码”目录。

配置 test 环境

以下以 Windows、Conda 和 NVIDIA GPU 为例。先安装 Anaconda 或 Miniconda，并确认显卡驱动可用。

conda create -n test python=3.10
conda activate test

已有 test 环境时只需激活。安装应用所需依赖：

python -m pip install --upgrade pip
python -m pip install torch==2.9.0 torchvision==0.24.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements-app.txt

以上 PyTorch 安装源与项目安装脚本一致，对应 CUDA 12.8，需兼容的 NVIDIA 驱动。已有可用环境时，先检查再决定是否安装：

python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

配置 DepthPro

应用会优先复用随包提供的 DepthPro 源码；未包含时安装项目采用的官方版本：

python -m pip install "depth_pro @ git+https://github.com/apple/ml-depth-pro.git@9efe5c1"

Apple DepthPro 官方仓库

准备模型权重

将项目配套权重放到下列位置。VATD 与 EBB 对应不同训练范围，不可互换。

项目目录/
├── competition_app/
├── train.py
├── train_vatd_physical_v3.yml  （VATD 配套配置，需与权重匹配）
├── weights/
│   ├── VATD_weight.pth
│   └── EBB_weight.pth
└── checkpoints/
    └── depth_pro.pt

DepthPro 权重可从 Apple 官方下载地址 获取。随包 DepthPro 目录中已有权重时，应用也会自动复用。

已有权重，无需执行训练

VATD 还需要与权重配套的 train_vatd_physical_v3.yml。当前文件包缺少此配置，需补齐后使用 VATD；EBB 已通过本机推理验证。请保留 train.py：当前推理流程会引用其中的定义。保留文件与执行训练是两回事，启动网页只需执行下一节命令。

启动与验证

在项目目录中运行：

conda activate test
python scripts/verify_install.py
python -m competition_app

服务启动后打开 http://127.0.0.1:7860。运行期间保持终端开启，按 Ctrl+C 停止服务。

当前电脑也可双击 启动无界光圈网页.bat，使用 D:\Anaconda\envs\test\python.exe。迁移到其他电脑时需按实际环境路径调整。

常见问题

网页能打开，但无法生成图像

检查权重与 DepthPro 是否齐全，并查看终端错误。服务启动成功不等于模型已成功加载。

提示显存不足

优先在工作台把处理尺寸调到 512、640 或 768 px 后重试，并关闭其他占用 GPU 的程序。若需要限制部署环境允许的最大手动尺寸，可在启动前设置：

$env:BOKEH_MAX_CUSTOM_LONG_SIDE="1024"
python -m competition_app
能否断网运行？

完成依赖与权重下载后，推理在本地执行。建议比赛前断网测试一次上传、对焦、渲染和下载流程。

如何更换端口？
$env:BOKEH_PORT="7861"
python -m competition_app

然后访问 http://127.0.0.1:7861。
